# CodeCollab

CodeCollab is a modern collaborative code editor UI built using HTML, CSS, and JavaScript. Inspired by tools like VS Code, Replit, and CodeSandbox, it provides an interactive coding experience with a clean developer-focused interface.

## Features

* Interactive code editor
* Run JavaScript directly in browser
* Console output panel
* File switching system
* Language templates (JS, Python, C++)
* Dark/Light theme toggle
* Live collaboration simulation
* Responsive modern UI

## Tech Stack

* HTML
* CSS
* JavaScript

## Getting Started

1. Clone the repository
2. Open `index.html`
3. Start coding
